Privacy policy

rclone triage · Updated 10 October 2026

This policy describes the rclone triage desktop application and its Google Drive OAuth integration. The person or organisation running the tool is responsible for their authority to access an account and for the files and records they collect.

Information accessed and its purpose

When you authorise Google Drive, the application uses OAuth access and refresh tokens to request file and folder metadata and to download the file contents you select. Its new Google Drive sign-in flow requests https://www.googleapis.com/auth/drive.readonly. The data is used for user-directed listing, inspection, acquisition and related local records. Google handles your sign-in; you do not give your Google password to this OAuth integration.

Other, separately selected workflows can import existing provider configurations, inspect local browser profiles or record system information. Those workflows may handle cookies, credentials and account information. Imported configurations can have different permissions from this application's new Google Drive sign-in flow.

Storage and retention

OAuth client credentials are saved in the application's local configuration. Access and refresh tokens can be stored in rclone configurations and working case snapshots. Downloaded files, listings, manifests, reports and logs are written to local case or output locations chosen by the operator. These records can contain private filenames, paths, metadata and credentials.

Case files and saved configurations are not automatically deleted when you close the application. The operator controls retention, backups, access restrictions and deletion. Deleting a working configuration does not remove copies in case folders, exports or backups. Temporary-runtime cleanup is separate from deletion of collected evidence.

Sharing and network connections

The application communicates with Google or another selected storage provider to authenticate and perform requested operations. Runtime downloads and update checks contact the project's GitHub releases or rclone distribution sources. The project does not operate a cloud backend that receives your Google Drive contents as part of this desktop OAuth flow.

The application does not automatically send case files or diagnostic archives to the developer. Operators can export and share records themselves; review them before sharing. Google user data is not used by this project for advertising, sold to third parties, or used to train general-purpose AI models.

Google API Services User Data Policy

rclone triage's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting local data

You can revoke the application's access through your Google Account third-party access settings. Revocation prevents continued authorised access using that grant; it does not delete files already downloaded. To remove local data, delete the relevant saved configurations, case outputs and any copies or backups you control, subject to your applicable retention obligations.

This website and support

This static website is hosted by GitHub Pages. It has no application login, advertising scripts or analytics added by this project. GitHub handles website requests under its privacy statement. If you email support or open a GitHub issue, the information you send is handled by those communication services. Do not include credentials or private case material.

For privacy or OAuth consent questions, contact michael@theablecoder.io. Changes to these practices will be reflected on this page.
