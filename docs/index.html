rclone triage

View cloud files, choose what to collect, and save local copies with a record of each transfer.

rclone triage is an open-source Windows desktop application with a terminal menu and command-line interface. It embeds a verified rclone runtime and supports authorised cloud triage and acquisition.

Under development. Nightly builds are test builds; provider testing is incomplete. Use only with accounts and data you are authorised to access.

Connect Google Drive

The application opens Google's sign-in and consent screen. Its Google Drive sign-in flow requests drive.readonly to list files, read metadata and download selected contents. This permission does not allow uploading, editing or deleting Drive files.

The desktop application connects to Google from your computer. Acquired files and case records are stored in the output folder you choose. Read the privacy policy before authorising access.

Get started

Download a Windows nightly for x64, x86 or ARM64, then follow the setup instructions. Protect the case folder: saved account settings can contain credentials.

Support

For support or questions about this app, use the issue tracker. Do not post tokens, credentials, case files or private account information.
